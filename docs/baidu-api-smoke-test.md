## 结论

当前开发 AK 可以正常调用坐标转换、步行路线、步行 RouteMatrix 和基础地点检索接口。

RouteMatrix 返回的是起终点之间的距离和耗时，不是完整道路拓扑。它可以作为采样数据或路线参考，是否作为 C++ 等时圈算法的主要输入，需要结合人工路网方案进一步确定。

地点检索接口返回了有效 POI，但每天可用额度、不同服务的具体配额和长期稳定性仍需在百度控制台单独确认。

本记录用于记录 API 连通性和样例结果，不代表完整精度验证。
