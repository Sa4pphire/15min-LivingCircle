# 路网编辑器稳定性排查（2026-10-07）

用户报告浏览器提示意外崩溃。排查时 5174 前端和 8001 API 均正常运行，近期服务日志没有退出或异常堆栈。
未捕获到原始浏览器崩溃堆栈，因此以下是已确认并修复的资源压力问题，不能认定是原提示的唯一原因。

## 已确认的问题与修正

- 每次编辑都通过 JSON 深复制整张图，保留 30 份撤销状态；改为不可变记录和仅包含变化节点、边的撤销记录。
  历史同时限制步数和内存预算，最近一次操作仍可撤销。节点移动、形状调整、拆分和删除均保持可恢复。
- 每次鼠标移动都重新绘制全部底图、扫描全图节点，并为所有路段临时分配坐标数组。
  改为缓存地图底层、预计算边界和节点网格查找；只有地图、图层或路网变化时重画底层。
  鼠标交互和坐标显示按动画帧合并，绘制只处理当前可见范围。
- 高分屏会扩大画布缓冲，批量选中会一次挂载所有属性行。
  画布缓冲限制为 400 万像素，多选列表每页 100 条，删除预览最多展示 200 个 ID；批量操作仍覆盖全部所选路段。
- 极端坐标会使以浮点坐标递增的网格循环无法前进。
  改为有限次数的索引循环，并限制视图缩放范围；不改变路网坐标或连接关系。

## 同类操作的前后测量

使用隔离的 Edge 测试页，1440 × 920、设备像素比 2。初次排查时路网为 6,990 个节点、7,823 条边；
用户仍在继续修改路网，测试期间源图有变化，以下是同类操作的测量，不是固定数据集的严格性能基准。
测试增加 60 个节点、移动鼠标 160 次并撤销 10 次，测试修改没有保存到源路网。
内存是强制 GC 后的 JavaScript 堆，**不包含浏览器进程、GPU 或画布的原生内存**。

| 指标 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 初次加载 JavaScript 堆 | 8.79 MiB | 10.02 MiB |
| 编辑 30 次后 JavaScript 堆 | 111.44 MiB | 11.23 MiB |
| 编辑 60 次后 JavaScript 堆 | 111.69 MiB | 11.30 MiB |
| 160 次鼠标移动的页面任务耗时 | 1,622.9 ms | 237.4 ms |
| 60 次编辑的操作总耗时 | 1,964 ms | 1,053 ms |

修复前和修复后的这轮测试均未发生浏览器崩溃。测量证明资源压力明显下降，不证明所有浏览器环境下的异常均已消除。

## 验证

验证了增删节点、孤立端点清理、多选删除、连线类型、搜索选点、移动与形状调整、撤销和重做、
JSON 导入导出、图层切换及移动端布局；当前图经过配置的 Debug C++ 引擎校验。
新增单元检查覆盖变化记录、删除与拆分的恢复顺序、导入重排序、内存预算和极端坐标循环。
长压力测试另覆盖连续 200 次编辑、大范围多选、删除预览、重复缩放与 4K 视图。
在用户确认崩溃常发生于连续编辑或撤销后，又补测了连续 200 次编辑和 180 次撤销／重做指令。
该轮加载用户当时保存的 6,632 个节点、7,389 条边：编辑后 JavaScript 堆约 11.41 MiB，
多轮撤销／重做后约 12.24 MiB，大范围多选后约 11.76 MiB；没有页面错误或崩溃。

若浏览器仍提示意外崩溃，需要结合具体触发操作、错误代码以及浏览器／宿主的崩溃记录继续判断；
页面 JavaScript 错误与浏览器渲染进程意外退出是不同层面的故障。
