# 路网编辑器

双击根目录的 `start-demo.bat`，会启动生活圈主站、独立编辑器和共用后端，只自动打开生活圈展示页。
编辑器地址为 `http://127.0.0.1:5174/`，主站使用 `5173`，两者分别运行前端进程，共用 `8000` 上的 Python API 和 C++ 引擎。
需要编辑时手动打开编辑器地址。主站区域列表页、地图页的编辑入口已移除，旧 `?mode=editor` 地址不再打开编辑器。
已有依赖按项目 README 安装；启动器不会自动安装依赖。停止三个服务运行
`start-demo.bat stop`，更新代码后运行 `start-demo.bat restart`，或再次双击脚本。

旧端口 `5173` 的浏览器草稿不会自动迁移到 `5174`。切换前在旧编辑页恢复草稿，再保存到后端或使用“导出 JSON”交给新编辑器导入；“下载草稿”文件不能直接作为完整路网导入。已经保存的区域文件无需迁移。
更新发布功能后需要重启编辑后端，才能使用新增 API。

## 工具栏与面板

工具栏分为基础、进阶两层，右侧只显示当前功能需要的面板。常用保存、撤销和重做保留直接入口，图层独立切换；原有工具和快捷键继续使用。

| 层级 | 统一入口 | 包含的操作 |
| --- | --- | --- |
| 基础 | 选择与属性 | 单选、多选、查找、节点/路段属性和批量修改 |
| 基础 | 绘制道路 | 连续绘制、独立节点、已有节点连线与连接类型 |
| 基础 | 调整结构 | 移动/删除节点、拆分路段、形状点调整 |
| 进阶 | 检查与优化 | 路网校验、路径检查、局部精化与候选审阅 |
| 进阶 | 自动建图 | 路口生成、本地 OSM 轮廓及各自的预览/采纳 |
| 进阶 | 区域与发布 | 切换区域、导入/导出 JSON、框选打包、重新加载、发布 MySQL |

自动建图中的路网草案和本地轮廓仍是不同数据，各自明确采纳或取消。切换面板不会把未采纳内容写入文件；工具栏保留返回待处理预览的入口。局部精化仍需设置起点、评估、填写依据并逐项审阅，不因归组而自动改图。

## 保存与发布

“保存本地”沿用原保存校验、备份和写入逻辑。进阶“区域与发布”中的“发布到数据库”只发布已经保存的完整区域包，包含路网、POI、标定、底图与编辑源文件。

1. 处理生成/轮廓预览，保存当前修改。
2. 打开“区域与发布”，查看发布配置状态。
3. 点击“发布到数据库”，成功后显示数据库内容版本。
4. 使用 MySQL 的展示后端重启后加载该版本；本地编辑器继续使用文件模式。

未保存修改、待处理生成/轮廓预览和正在执行的操作会阻止发布。后端会核对文件修订，拒绝过期画布版本；数据库失败不影响此前的本地保存。配置状态只表示服务端参数和驱动就绪，不代表已连接数据库，发布时才实际连接。

首次使用需要配置根 `.env` 的 `MYSQL_*`、安装可选驱动并初始化表，详见 [MySQL 本地编辑器发布](mysql-region-storage.md#本地编辑器发布)。本地编辑服务仍设为 `REGION_STORAGE_BACKEND=file`；设为 `mysql` 会关闭编辑器，不能用切换读取模式代替发布配置。

## 操作

- **局部精化（2026-10-28）**：选中一个路网节点，在进阶“检查与优化”的“局部精化”面板设为起点，设置本轮评估数量与等待情景后评估。列表按已评估的15分钟节点判定变化排序；预算外、不具备方案和已有审阅分别标记。可定位查看端口与过街，填写依据后应用“允许/不设过街”或等待参数；一次应用可撤销，再用“保存本地”写入。计划不直接改图，编辑后需重新评估。情景排序是核查线索，不能当作实测精度或全图误差范围，详见[主动局部精化说明](active-local-refinement.md)。当前实现尚未完成运行验收。

- **自动生成路网（2026-10-28）**：打开带 OSM 道路源图的区域，在进阶“自动建图”中生成路网。系统从当前画布增量补全普通路口，右侧显示生成、保留、待处理数量；可按分类定位路口，下载完整清单。绿线是新增/调整连接，灰虚线是将替换的旧线，橙虚线是未启用的推测过街。点击“采纳草案”后作为一次编辑进入撤销历史，再用“保存本地”持久化；取消不改当前图，继续手动编辑会清除旧预览。
  已有人工路口、手工改动/删掉的连接、现有过街和待连线的独立节点受到保护。再次生成会保留已生成路口，不重复叠加。过街默认不自动启用，采纳后可用现有“连线 → 过街”工具确认连接。双幅、多节点复杂路口、独立步道及证据不足的节点列为待处理，当前连接保持原样。
  这一版消费区域内已有道路源数据，**尚未提供空白区域一键下载 OSM 并建图**；空白或 engine-snapshot 区域不能使用此入口。新版前端/后端需要一起加载。2026-10-28 曾在本地执行全图生成、保存并审阅数据差异，这是历史本地运行记录。本次提交不包含当时生成后的路网数据或审阅产物，也未重新运行功能测试、构建或浏览器联调，不能把该记录视为当前提交的运行验收。

- 右侧“本地轮廓”面板点击“生成本地轮廓”，或工具栏“本地轮廓”（C）：拖动框选街区，点击“开始生成轮廓”。空白区域也可使用。生成后自动切换到本地轮廓预览；右侧点击“保存轮廓到区域包”替换本区域的 `context.json`，或“取消预览”恢复已保存底图。生成和保存保留当前未保存路网修改。
  单边最多 6 公里、面积最多 25 平方公里。首次生成需要网络；新建 BD-09 区域的对齐使用现有 `BAIDU_SERVER_AK` 和官方坐标转换缓存。OSM 覆盖不足、下载或转换失败时保留原底图。保存前备份 `context.json` 和 `manifest.json`，保存后同步更新校验和；后续框选包带上轮廓及来源信息。轮廓是展示参考，不建立步行连通关系。

- 选择区域包界面有“创建新区域包”。输入大概位置（如“广东广州”或“广州天河区”），可选填写名称，点击“创建并打开编辑器”。通过现有浏览器地图 AK 查询地点，创建空白路网草稿并自动显示当地百度底图。草稿可以保存节点、重新打开；新增步行通道后经过 C++ 检查保存。新建区域工作画布可以平移和缩放到周边街区。

- 进入编辑器先选择区域包。区域列表读取 `data/regions/` 中已有目录，显示名称、版本、路网数量和范围；清单或校验和异常的包会显示错误。左上角返回和“区域与发布”中的“切换区域”均返回区域包列表，未保存修改保留为该区域的本机草稿。编辑另一个包无需改变主分析页的默认区域。
- 右侧“辅助底图”选择“百度地图”即可叠加在线底图；沿用 `frontend/.env.local` 的浏览器 AK。缩放、拖动、选点和节点移动使用包内 BD-09 校准网格进行双向换算。加载失败、缺少 AK 或区域过窄时可继续使用本地底图。
- 工具栏“框选打包”（B）或右侧“框选区域”：拖动矩形后预览路段、节点和裁剪端点数，填写名称、标识和版本，点击“生成并下载区域包”。新包自动加入列表，可直接打开继续编辑；当前画布上的未保存修改也会进入新包，原包不被覆盖。具体裁剪规则见 [区域包说明](region-packages.md#编辑器框选导出)。

- 滚轮以鼠标所在位置为中心缩放，百度底图合并触控板的细小滚动后逐级缩放，比例尺随实际距离更新并自动显示米或公里；拖动空白、右键或中键拖动平移。“样区”和“全图”复位至当前路网范围中心，视野留在路网数据外接范围内。
- “选择”点击路段或节点，右侧显示 ID、连接和属性。输入 ID、道路组或 OSM 编号可搜索定位。
- 按住 Shift 点击路段可加入或取消多选，Shift 拖动可框选经过矩形的路段；隐藏图层不参加框选。
  也可打开工具栏的“多选路段”，直接点选或拖动框选，右键仍可平移。搜索结果同样支持追加选择。
  多选后右侧显示路段清单、数量和总长度，可逐条取消、批量删除或设置类型与过街等待。
  批量等待只应用到过街边；留空的属性保持原值。批量修改或删除可一次撤销，Esc 或“清空选择”取消选择。
- “移动节点”拖动节点，所有相连路段的端点同时更新；也可在属性栏输入精确米数。
- 工具栏“删除节点”（D）自动显示节点，点击节点后确认删除；确认框列出会一起删除的相连路段。
  可连续删除多个节点，也可在节点属性栏点击“删除节点”。相连路段移除后，新孤立的端点也一起清理。
  Ctrl+Z 同时恢复节点、相连路段和被清理的端点。
  绑定设施入口的相连路段或被标注为裁剪出口的节点，需先处理引用再删除。
- “新增节点”（N）恢复为独立工具：点击地图建立节点，不自动连接；可随后用“连续绘制”或“连线”接入路网。
- “连续绘制”（P）：先点已有节点作为起点，随后每次点击空白都建立一个节点，并自动与上一节点连线。双击最后一点结束绘制，双击只产生一个末端节点；也可按 Enter 或点击“完成绘制”。空白区域没有节点时，首次点击建立起点。
  默认绘制步行通道，可在工具栏选择转弯或过街类型；点击已有节点会明确接入该节点，不建立重复节点。每一段及它的新节点作为一次撤销操作，Ctrl+Z 可逐段撤回；Esc 或切换工具结束绘制并保留已画内容。绘制过程中右键／中键或 Alt 拖动平移。
- 原“连线”（L）保留：先选起点节点、再选终点；中途点击空白只增加折点，不新增路由节点。
  连线工具自动显示节点并在鼠标悬停时高亮。工具栏下方直接点击步行通道（walkway）、转弯或过街按钮选择类型。
  也可搜索节点 ID，依次点击节点搜索结果选起点和终点；选中节点时可点击“从此节点连线”。
  起点 ID 会显示在连线工具栏，点击“取消当前连线”可重选。完成后在属性栏设置道路组、接入约束、侧别、宽度或等待。分侧与共享是接入属性，不再是两种路段类型；已有边的这些规则保持不变。详见 [统一 walkway 说明](unified-walkways.md)。
- 接入已有路段中部时，先用“拆分路段”建立明确的拓扑节点，再连接。
  不自动吸附或合并重合节点；不自动连接几何交点。过街边不允许拆分，以免重复收取等待。
- 选中路段后拖动白色形状点调整线形；“添加形状点”后点击所选路段添加折点。形状点不会建立路网连接。
- 删除前会显示影响范围；删节点会同时删相连边。“撤销 / 重做”保留最近 30 次操作。
  撤销记录仅保存变化的节点和路段，受内存预算限制；很大的批量修改可能缩短可撤销步数，最近一次操作仍可撤销。
  单条或批量删除路段时，仅清理本次失去全部连接的端点；其他路段仍使用的节点和原有独立节点保留。
  确认框显示同步删除的节点数，撤销会一起恢复。
  快捷键 V / M / N / P / L / S / R 切换工具，其中 N 新增节点、P 连续绘制、L 连线。Delete 删除，Esc 取消，Ctrl+Z / Ctrl+Y 撤销或重做，Ctrl+S 保存。
- “路径检查”先选起点节点，再选终点。粉色路径来自当前画布的独立 Dijkstra，步速 1.3 米/秒；
  过街使用单边等待或默认 20 秒。此检查反映显式连接和成本，不能证明现场通行。
- “检查路网”执行结构检查并调用配置的 C++ 引擎验证当前图；引擎缺失或拒绝输入会显示错误。

## 保存与恢复

新建区域以 `originBd09` 保存百度查询得到的原点，使用近似局部米制坐标；不会将它标记为 WGS-84。空白或只有节点的区域标记为“草稿”，不作路由图使用；首条步行通道保存后标记为可用路网。区域入口列表保留这些草稿，方便继续处理。

“保存本地”首先检查 ID、端点、线形、道路侧别、等待和引用，经过 C++ 引擎验证后再写入：

1. 当前区域包 `source/annotations.json` 的 `manualGraphEdits`：相对基础图的节点、边增删改记录。
2. 当前区域包 `network.json`：应用人工编辑后的 C++ 输入。
3. 当前区域包 `manifest.json`：同步刷新内容校验和。

保存前的文件会自动备份到 `data/cache/network-editor-backups/<时间与编号>/`。
恢复某次备份时先停止编辑服务，将同一目录中的 `network.json`、`annotations.json` 和 `manifest.json` 分别复制回对应区域目录、`source/` 和区域目录，再重启并重新加载。
保存后重新发起 C++ 分析即可读取新图；已经完成的分析保持原结果。

导出脚本 `python backend/scripts/export_synthetic_preview.py --region-id <区域标识>` 会重复应用该区域的人工编辑。原始包以道路源图生成基础图；框选包以 `source/engine-base.json` 保存精确裁剪快照，两种来源均可回放编辑。
编辑记录绑定基础生成图的摘要；源拓扑或建模规则变化导致基础图变化时，导出明确失败，保留已有输出，
需要人工迁移编辑记录，不会静默把旧 ID 套到新图。其他窗口或外部脚本修改文件时，保存会拒绝过期版本。
原有路口标注保留作来源；`sourceGraph.manualGraphEdits` 列出覆盖、删除和新增的路由节点、边 ID。

“导出 JSON”下载当前完整 v2 图，便于留档；导出本身不改变运行数据。
“导入 JSON”仅接受同一坐标原点的 v2 合成图，通过 C++ 检查后载入画布；仍需保存才应用。
浏览器自动保存未提交草稿，重新打开可恢复。源文件已变化的草稿只能先下载后人工核对。

坐标为局部米制，X 向东、Y 向北；离线 OSM 参考底图在绘制时翻转南向 Y，无需地图 AK。
编辑和区域导出仅开放给本机开发服务，拒绝跨站请求和远程写入；生产环境不开放编辑接口。
图和人工编辑始终保留合成、未核实标记，不用于确认真实人行横道、入口或通行权限。

## 本地制作与服务器展示

编辑器继续作为本地数据制作工具。服务器以 `APP_ENV=production` 启动时不注册 `/api/v1/network-editor` 路由，编辑读写、校验、新建、轮廓生成、打包及编辑器下载接口均关闭；本地开发模式仍保留原有主机／来源检查。`LOCAL_CONTAINER_EDITOR=true` 不能覆盖生产环境限制。

独立编辑器启动时读取 `GET /api/v1/capabilities`。`networkEditor` 为 false 时显示关闭说明，不加载编辑器组件；能力接口读取失败时也不启用编辑器。主站无论这一能力是否开启，都不显示编辑入口，也不通过查询参数切入编辑器。能力接口只公开界面能力，后端路由限制仍是实际访问边界；独立端口并不代表独立后端或账号权限系统。

服务器数据流程是“本地编辑／核查 → 保存完整区域包 → 编辑器按钮或命令发布 MySQL → 展示后端重启读取发布版本”。[MySQL 发布说明](mysql-region-storage.md)已提供，数据库读取模式同样关闭编辑器；编辑制作继续用文件模式。Redis 尚未接入。此次工具栏整合与发布功能仅完成源码和差异审阅，没有启动服务、构建、连接数据库或运行测试。
