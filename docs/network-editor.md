# 路网手动编辑器

双击根目录的 `start-network-editor.bat`，浏览器打开 `http://127.0.0.1:5174/?mode=editor`。
编辑器复用 Vue 前端、Python API 和 C++ 引擎，以独立的 5174 / 8001 端口启动，避免占用原演示服务。
已有依赖按项目 README 安装；启动器不会自动安装依赖。停止编辑服务运行
`start-network-editor.bat stop`，更新代码后运行 `start-network-editor.bat restart`。
原演示页面顶部也有“编辑路网”入口；更新后需要重启其后端才能使用新增 API。

## 操作

- 右侧“本地轮廓”面板点击“生成本地轮廓”，或工具栏“本地轮廓”（C）：拖动框选街区，点击“开始生成轮廓”。空白区域也可使用。生成后自动切换到本地轮廓预览；右侧点击“保存轮廓到区域包”替换本区域的 `context.json`，或“取消预览”恢复已保存底图。生成和保存保留当前未保存路网修改。
  单边最多 6 公里、面积最多 25 平方公里。首次生成需要网络；新建 BD-09 区域的对齐使用现有 `BAIDU_SERVER_AK` 和官方坐标转换缓存。OSM 覆盖不足、下载或转换失败时保留原底图。保存前备份 `context.json` 和 `manifest.json`，保存后同步更新校验和；后续框选包带上轮廓及来源信息。轮廓是展示参考，不建立步行连通关系。

- 选择区域包界面有“创建新区域包”。输入大概位置（如“广东广州”或“广州天河区”），可选填写名称，点击“创建并打开编辑器”。通过现有浏览器地图 AK 查询地点，创建空白路网草稿并自动显示当地百度底图。草稿可以保存节点、重新打开；新增步行通道后经过 C++ 检查保存。新建区域工作画布可以平移和缩放到周边街区。

- 进入编辑器先选择区域包。区域列表读取 `data/regions/` 中已有目录，显示名称、版本、路网数量和范围；清单或校验和异常的包会显示错误。左上角返回和右上角“切换区域”均返回区域包列表，未保存修改保留为该区域的本机草稿。编辑另一个包无需改变主分析页的默认区域。
- 右侧“辅助底图”选择“百度地图”即可叠加在线底图；沿用 `frontend/.env.local` 的浏览器 AK。缩放、拖动、选点和节点移动使用包内 BD-09 校准网格进行双向换算。加载失败、缺少 AK 或区域过窄时可继续使用本地底图。
- 工具栏“框选打包”（B）或右侧“框选区域”：拖动矩形后预览路段、节点和裁剪端点数，填写名称、标识和版本，点击“生成并下载区域包”。新包自动加入列表，可直接打开继续编辑；当前画布上的未保存修改也会进入新包，原包不被覆盖。具体裁剪规则见 [区域包说明](region-packages.md#编辑器框选导出)。

- 滚轮以鼠标所在位置为中心缩放，百度底图合并触控板的细小滚动后逐级缩放，比例尺随实际距离更新并自动显示米或公里；拖动空白、右键或中键拖动平移。“样区”和“全图”复位至当前路网范围中心，视野留在路网数据外接范围内。
- “选择”点击路段或节点，右侧显示 ID、连接和属性。输入 ID、道路组或 OSM 编号可搜索定位。
- 按住 Shift 点击路段可加入或取消多选，Shift 拖动可框选经过矩形的路段；隐藏图层不参加框选。
  也可打开工具栏的“多选路段”，直接点选或拖动框选，右键仍可平移。搜索结果同样支持追加选择。
  多选后右侧显示路段清单、数量和总长度，可逐条取消、批量删除或设置类型与过街等待。
  批量等待只应用到过街边；留空的属性保持原值。批量修改或删除可一次撤销，Esc 或“清空选择”取消选择。
- “移动节点”拖动节点，所有相连路段的端点同时更新；也可在属性栏输入精确米数。
- 工具栏“删除节点”（D）自动显示节点，点击节点后确认删除；确认框列出会一起删除的相连路段。
  可连续删除多个节点，也可在节点属性栏点击“删除节点”。相连路段移除后，新孤立的端点也一起清理。
  Ctrl+Z 同时恢复节点、相连路段和被清理的端点。
  绑定设施入口的相连路段或被标注为裁剪出口的节点，需先处理引用再删除。
- “新增节点”点击空白建立节点。“连线”先选起点节点、再选终点；中途点击空白可增加折点。
  连线工具自动显示节点并在鼠标悬停时高亮。工具栏下方直接点击步行通道（walkway）、转弯或过街按钮选择类型。
  也可搜索节点 ID，依次点击节点搜索结果选起点和终点；选中节点时可点击“从此节点连线”。
  起点 ID 会显示在连线工具栏，点击“取消当前连线”可重选。完成后在属性栏设置道路组、接入约束、侧别、宽度或等待。分侧与共享是接入属性，不再是两种路段类型；已有边的这些规则保持不变。详见 [统一 walkway 说明](unified-walkways.md)。
- 接入已有路段中部时，先用“拆分路段”建立明确的拓扑节点，再连接。
  不自动吸附或合并重合节点；不自动连接几何交点。过街边不允许拆分，以免重复收取等待。
- 选中路段后拖动白色形状点调整线形；“添加形状点”后点击所选路段添加折点。形状点不会建立路网连接。
- 删除前会显示影响范围；删节点会同时删相连边。“撤销 / 重做”保留最近 30 次操作。
  撤销记录仅保存变化的节点和路段，受内存预算限制；很大的批量修改可能缩短可撤销步数，最近一次操作仍可撤销。
  单条或批量删除路段时，仅清理本次失去全部连接的端点；其他路段仍使用的节点和原有独立节点保留。
  确认框显示同步删除的节点数，撤销会一起恢复。
  快捷键 V / M / N / L / S / R 切换工具，Delete 删除，Esc 取消，Ctrl+Z / Ctrl+Y 撤销或重做，Ctrl+S 保存。
- “路径检查”先选起点节点，再选终点。粉色路径来自当前画布的独立 Dijkstra，步速 1.3 米/秒；
  过街使用单边等待或默认 20 秒。此检查反映显式连接和成本，不能证明现场通行。
- “检查路网”执行结构检查并调用配置的 C++ 引擎验证当前图；引擎缺失或拒绝输入会显示错误。

## 保存与恢复

新建区域以 `originBd09` 保存百度查询得到的原点，使用近似局部米制坐标；不会将它标记为 WGS-84。空白或只有节点的区域标记为“草稿”，不作路由图使用；首条步行通道保存后标记为可用路网。区域入口列表保留这些草稿，方便继续处理。

“保存到 C++ 路网”首先检查 ID、端点、线形、道路侧别、等待和引用，经过 C++ 引擎验证后再写入：

1. 当前区域包 `source/annotations.json` 的 `manualGraphEdits`：相对基础图的节点、边增删改记录。
2. 当前区域包 `network.json`：应用人工编辑后的 C++ 输入。
3. 当前区域包 `manifest.json`：同步刷新内容校验和。

保存前的文件会自动备份到 `data/cache/network-editor-backups/<时间与编号>/`。
恢复某次备份时先停止编辑服务，将同一目录中的 `network.json`、`annotations.json` 和 `manifest.json` 分别复制回对应区域目录、`source/` 和区域目录，再重启并重新加载。
保存后重新发起 C++ 分析即可读取新图；已经完成的分析保持原结果。

导出脚本 `python backend/scripts/export_synthetic_preview.py --region-id <区域标识>` 会重复应用该区域的人工编辑。原始包以道路源图生成基础图；框选包以 `source/engine-base.json` 保存精确裁剪快照，两种来源均可回放编辑。
编辑记录绑定基础生成图的摘要；源拓扑或建模规则变化导致基础图变化时，导出明确失败，保留已有输出，
需要人工迁移编辑记录，不会静默把旧 ID 套到新图。其他窗口或外部脚本修改文件时，保存会拒绝过期版本。
原有路口标注保留作来源；`sourceGraph.manualGraphEdits` 列出覆盖、删除和新增的路由节点、边 ID。

“导出 JSON”下载当前完整 v2 图，便于留档；导出本身不改变运行数据。
“导入 JSON”仅接受同一坐标原点的 v2 合成图，通过 C++ 检查后载入画布；仍需保存才应用。
浏览器自动保存未提交草稿，重新打开可恢复。源文件已变化的草稿只能先下载后人工核对。

坐标为局部米制，X 向东、Y 向北；离线 OSM 参考底图在绘制时翻转南向 Y，无需地图 AK。
编辑和区域导出仅开放给本机开发服务，拒绝跨站请求和远程写入；生产环境不开放编辑接口。
图和人工编辑始终保留合成、未核实标记，不用于确认真实人行横道、入口或通行权限。
