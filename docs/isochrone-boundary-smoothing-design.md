## 1 当前界面与使用

C++路网计算完成后，地图直接绘制后端返回的平滑轮廓。右上角不再显示本算法的状态栏、显示开关、原始虚线叠加、指标说明或导出按钮。

两条渲染路径（百度地图覆盖层和无底图SVG）统一优先使用新版平滑面。旧结果缺少新版字段时保持原有原始面兼容，旧保守面不会被标记成新版平滑面。

当前[启动器](../start-demo.ps1#L456)的uvicorn参数没有 --reload，后续若修改Python算法，需要重启后端才能加载。此次仅删除前端面板并固定显示行为，后端算法未改，加载新版前端即可获得新界面。本次没有代用户启动或重启服务。

## 2 旧版无法选择的原因

原界面根据报告是否包含对应档位的几何决定是否禁用选项。当前结果缺少aggressive字段时，该选项就会被disabled，同时显示选择器会回到原始面。这是从源码确认的直接触发条件。

前端已经刷新而后端仍运行旧代码，或者仍展示旧分析结果，都可以造成这一条件。本轮没有读取用户那次实际响应，不能把其中某一种情况当作已实证结论。

单模式重写删除了多档映射和禁用逻辑；在用户确认效果后，当前主界面进一步删除了整个调试面板。后端诊断字段仍保留在响应中。

## 3 唯一平滑算法

处理流程为原始米制MultiPolygon → 保留原顶点并补充弧长采样 → 固定弧长参数的循环卷积 → 地图坐标转换 → SVG显示。

[入口](../backend/app/boundary_smoothing.py#L138)只生成一份平滑轮廓。旧的多档执行器、STRtree保护索引、道路/frontier覆盖保护、转角和窄口权重、位移clamp、面积预算、拓扑验收及减强度重试均已删除。

当前参数：

| 参数 | 当前值 |
| --- | --- |
| 输入网格h | 由引擎请求传入，当前10米 |
| 弧长采样间距 | 约h/4，即2.5米，并保留原顶点 |
| 卷积邻域半径 | 2h，即20米；小环缩到周长1/6 |
| 核 | 17点三角权重，权重为(9−abs(j))/81，j从−8到8 |
| 轮数 | 4轮 |
| 原位置锚定、精度和覆盖限制 | 关闭 |

每轮通过固定参考弧长在当前坐标中插值取样，再加权平均。环起点按周长循环，输出显式闭合；点数和顺序保持对应。相对原始面的最大对应点位移可作为连续双向边界偏移的事后上界，仅记录，不用于拒绝结果。

这一算法允许尖角变圆、凹槽缩小、狭窄连接变形、整体收缩或几何自交。几何有效性只作诊断，原面和候选均有效时计算面积对称差、增加和删减面积；否则面积指标为null。只有无法构造有限闭环等输入/数值问题会保留原始面，不能把这种回退误解为几何精度保护。

## 4 单一结果契约

后端 `build_smoothed_display_geometry` 返回一个 `{geometry, metadata}`，不再返回profiles。

| API字段 | 用途 |
| --- | --- |
| isochrone.geometry | 原始面，保留既有业务口径 |
| displayIsochrone.geometry | 唯一平滑显示面 |
| metadata.boundarySmoothing | 直接诊断对象，包含mode=unconstrained及算法版本 |

删除displayIsochroneProfiles/defaultProfile等多档字段。POI补全后，同一geometryRevision且mode为unconstrained时复用单一显示面。

前端只接收smoothedDisplayArea与直接boundarySmoothing诊断；仅当mode=unconstrained才把报告中的displayIsochrone视为当前平滑结果。[自动显示选择器](../frontend/src/RealMapStage.vue)中的renderedDisplayArea直接将其用于主体填充与描边。原始displayArea继续用于面积、地点判定、灰区裁剪和相机范围，寻路与耗时使用原C++结果。

指标里的偏差相对原展示面，不表示真实步行误差；取消这些约束是本轮用户明确指定的实验方向。

## 5 对照导出

主界面导出按钮随状态栏一并移除。`frontend/src/boundarySmoothingExport.js`保留为开发排查工具，当前界面不导入或调用它。以下为工具能力记录，不是现有页面操作入口。

“对照SVG”导出原始与平滑两面板，使用相同范围和比例，附原始虚线、可达路段与frontier。保留完整几何坐标，不额外删点或舍入。缺少平滑结果时明确报错，不把原始面复制一份冒充平滑结果。

“数据JSON”的schemaVersion为2，含rawGeometry、smoothedGeometry、直接诊断及receivedAlgorithmVersion。缺少新版平滑数据时smoothedGeometry为null，仍可以导出以定位版本不一致。坐标采用前端preview-local-v1米制东/南框架，不是引擎原始东/北轴向。
