# 前端交互原型

这一版用于讨论界面设计和交互，不提供真实的 15 分钟生活圈计算结果。地图、设施、可达面、灰段及其数字均为**合成示意数据**，页面内也有明确提示。

## 启动

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址。构建检查使用 `npm run build`。

## 目前可操作的内容

- 第一屏点击示意地图选点，再点击地图右上角的“生成示意分析”；第二屏也可选择 A/B/C 预设起点，返回地图生成结果。
- 第一屏分为项目信息、横向铺满的地图和 `LIVING CIRCLE` 字样三部分。底部字母的分层错位效果自动循环，不依赖鼠标位置；开启“减少动态效果”时停止动画。
- 滚轮累计滑动一定距离后整屏翻页：地图演示独占第一页，控制面板在第二页；触屏可上下滑动，也可使用页面导航按钮。
- 在第二页控制面板点击服务类别，高亮对应设施和疑似灰段。
- 切换近似面、街段、灰段和设施点图层；点击设施点查看示意耗时。
- 起点以小圆点显示：绿色为已分析起点，橙色为待分析起点。
- 桌面鼠标在地图上显示“步行探针”；街段、设施和合成建筑轮廓切换不同的指针与探针形态。建筑点击只展示示意信息，不计入设施覆盖。
- 悬停街段、设施和服务类别可预览；点击设施或建筑后固定详情，点击街段可设置新起点。
- 主按钮与地图结果有按下、处理中和完成反馈；触屏与“减少动态效果”模式保留功能但收敛动画。
- 第二页内容较长时可在页内滚动；窄屏下起点、结果、服务类别顺序堆叠。
- 控制面板页底部使用保持字形比例的全宽 `GEOVIEW` 描边字；桌面鼠标滑过字母时，彗星状光迹仅在字形内部出现并逐渐消散。

入口是 `src/entry.js`。界面位于 `src/App.vue`，样式位于 `src/demo.css`，合成数据位于 `src/demoData.js`。原有的 `src/main.js` 和 `src/styles.css` 暂时保留，不被新入口使用。

## 后续真实数据对接

当前没有调用 Python 后端。`vite.config.js` 已预留 `/api` 到本地 `8000` 端口的开发代理。下一阶段应将 `demoData.js` 替换为统一的接口适配层，把后端结果里的 `displayPolygonMeters`、`reachableEdges`、各类灰段及设施耗时分别映射到地图与服务索引；地图底图及坐标转换也需要接入真实地理数据。不要将本版模拟时间或缺口比例用于正式报告。
