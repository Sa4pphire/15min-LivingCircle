# 主干道统一两侧人行道模型（2026-10-06）

## 本轮规则

按用户要求，不再对每条机动车道各生成一对可步行线。所有 1,310 条主干道源段都有明确 `majorSidewalkPolicy.selections`：

- 相向双车道按同一物理道路处理，只保留各车道远离另一车道的外侧，整体两条纵向人行道。
- 单幅道路保留左右两侧，两条人行道均可双向行走，不受机动车 `oneway` 限制。
- `left/right` 仍按转换为引擎“向北 Y 正”后的原始边方向定义；反向车道的两个外侧可以都叫 `right`，不能理解成只留下整个道路的右边。
- 路口的 `turn`、`crossing` 保留：同角转弯不等待，横穿道路计一次指定等待；删除中央伪人行道与其旧中间端口。JSON 仍在节点处分段，不是每条长街只存两个边对象。

## 数据链与实现

统一维护 `synthetic-preview.annotations.json` 的 `majorSidewalkPolicy`，前端源图生成器将同一规则挂到 `demoRoadGraph.local.json`，Python 的 `major_sidewalks.py` 将它应用到 v2 步行图。每条生成的 sidewalk 保留 `sourceMajorEdgeId`，支持校验被保留的侧属于哪条源段。旧 `dividedRoadSections` 是可复现历史规则，当前全图模式不再执行局部遮罩。

道路配对使用已有道路名称／层级、相向车道、局部几何与原显式接近方向校对；规则冻结为具体源边和对应车道 ID。仅继承外侧的短接续段明确属于合成假设。高架、地面、隧道的配对层级分别保留，无名及不能确定对应的单幅支线不与旁边道路强行合并。因此该模型不是对全部现实人行道存在性或开放状态的证明。

36 个旧内侧路口端口投影到已有对应外侧。弯曲路段仍按原物理接近方向分组，不因两侧局部切线有差异就再拆成多个“街口”。检查器独立检查原端口归属、实际行进方向、街角连接、重复边和免费过街旁路。

两对分车道的旧路口合并成各一个物理路口：`crossroad-d57eaf8fe2a8`／`crossroad-f7458615b64f`，以及 `crossroad-75772ead6623`／`crossroad-2eb33a6e3cef`。合并必须具备已有内部连接路径，不只按距离或路名；后一处的二度汇合旁路被一并退役。原 ID 与内部边保存在 `mergedJunctions`，没有静默丢弃。

原接入机动车中心的独立共享支路端点迁到外侧，避免走进车道再折返。13 条旧共享／转向连接横跨同一道路两侧，改为使用引擎默认等待的 crossing，不能通过共享支路免费换侧。两处原人工蓝点过街仍保留，输出中的接入节点、边引用更新为实际存在的外侧段。

| 引擎节点／边 | 8,169／9,025 | 7,175／8,071 |

| 显式物理路口 | 70 个分车道模型 | 68 个模型，原 70 个均保留或有合并记录 |

小型独立回归验证双车道仅两条外侧、反向几何、未标过街不可换侧、整条道路只等待一次、原中心共享连接不能免费穿越；全图所有路口再次做独立规则和 C++ Dijkstra 对照。

Release 串行相关回归 344 项全部通过，无跳过；前端路网测试 26 项及生产构建通过。Debug 整批为 343 项通过、1 次子进程通信超时；该用例与新模型用例单独复核 13 项通过，不能把 Debug 整批记为全通过。首轮并行测试还出现过通信超时及 Python 进程访问异常，未改大 25 秒上限掩盖问题；Release 当前串行无此异常。C++ 算法源代码未修改或重新编译。

旧局部遮罩单元测试明确禁用全图策略，继续验证历史删除边界及拒绝错误连接；全图测试另行确认全部主干道规则、外侧引用、路口归属和无免费穿越。实际导出脚本重生成的 JSON 与运行文件 SHA-256 一致：`1e5f476635f08d2fb6e47a31964065df881033e2d8865702160f34e2ae6b8cac`。

学校东门的近似复现起点路线仍为约 135.39 米／104.15 秒；国泓路场景约 1,143.49 米／899.61 秒，含 20 秒过街等待。Debug、Release 实际结果均与独立节点最短路成本一致。末端和离路起点的直线接入仍为未核实估算。

前端界面、起点选区、缩放及 C++ 算法核心未修改。快速模式与专家模式共用带规则的源数据，但快速模式的浏览器动画不等于精确人行道路由；本轮规则主要约束专家模式的步行图。道路以外的公园／小区步道未作为机动车道内侧线清除，访问限制继续沿用上轮源核查。

重新发起分析才会使用新图；旧分析上下文不改写。生成顺序仍为 `node frontend/scripts/build-demo-road-graph.mjs --write`，再运行 `.venv/Scripts/python.exe backend/scripts/export_synthetic_preview.py`。SVG 对比与诊断下载仅在本地任务目录，不参与运行、不提交。
