# 全图源拓扑与十字路口校对（2026-10-06）

## 范围与结论

对现有地图展示范围内全部 2,643 条原始 OSM 道路核对节点和权限，不新增模式专属路网。共同源图为 `frontend/src/data/demoRoadGraph.local.json`，专家步行图由 Python 转换生成；快速模式也消费同一源图，但浏览器动画并不因此具有精确的过街耗时。

数据仍是合成／在线推定的联调路网，不能作为真实出行结论。没有根据截图自动补合法横道，也没有改 C++ 寻路、等时圈面算法或前端界面。

## 修正内容

- 从 OSM API 重新取得现有道路的 `nodeIds`、访问标签和共同节点位置，统一保存为离线生成依据。恢复 1,258 处简化时丢失的共享源节点；只有共同 OSM 节点 ID 才能支持连接，不按几何距离连通。
- 排除 491 条不满足当前步行许可规则的道路：明确 `foot=no/private/use_sidepath`、无明确步行许可的 `access=private/no`，以及无明确步行许可的自行车道。没有标记许可限制的地方仍属未核实，而不是已确认公共道路。
- 迁移 38 个旧子段引用，限定在同一原始 way、同类边且包含旧几何的唯一新子段。保护人工标注父边，不因子段编号变更丢失路口规则。
- 私有支路 `479194749` 从 `crossroad-cbac250bbc1e` 移除，剩余三向按 T 形路口重新构建。私有道路 `46974625`、`1116719052` 对应的两处旧路口规则撤销，保留连续道路；旧注释完整留存，不隐藏历史。
- `marked-east-path-gap` 原端点仅依赖私有道路 `225933176`，撤销这条旧未核实补线并保留记录。西侧旧人工补线仍有效并保留。
- 16 条来源标注横道的 way 改为带等待的 `crossing`。一条横道的纯形状点合并成折线，只等待一次；四条横道含中间分支，保留按腿等待并标记待核查，不推定安全岛或免费横穿。
- 带闸门／限制访问节点的新增连接列为待核查，不自动恢复。

## 学校东门绕行复现

截图目标“上海音乐学院实验学校-东门”的导航位置在当前引擎坐标约为 `[282.737691,-353.589353]`。旧自动绑定边 `w:225933191:3:0:s1` 属于 `foot=no` 自行车道；它并不是合法步行入口。

以附近 `[240,-300]` 为**近似复现起点**，不是从截图恢复的精确起点：Release 引擎旧路径约 886.17 米／681.67 秒，新图约 135.39 米／104.15 秒。新路线经过恢复连接的步道，不再走北／东大圈。末端约 4.10 米接入仍是未核实的估算直线；旧禁止道路绑定不再保留，不能将这次改动宣称为已调查学校入口。

扫描基于**已存在的源节点拓扑**，不遗漏现有度数为四的源节点，但不代表所有几何十字交点都已修复。另有 945 条主干道源节点记录不交由共享通道自动恢复：495 条已在所有相关道路存在，450 条需进一步设计缺失的源锚点及对应人行道端口。这 450 条还可能包括 T 形接入、普通分段、信号节点，不应全称为缺失十字路口。另有 50 条人工规则占用边、20 条端点几何不符、2 条闸门／访问限制节点和 1 条超出保留几何的连接保持待核查。

## 验证与维护

回归覆盖源权限、共享源节点、未连接几何相交、街角转弯、带等待过街、原中心旁路、撤销／迁移引用、横道折线合并、学校东门及国泓路路线，并以独立 Dijkstra 成本作对照。现有 `cpp-engine/build/poi-route/Debug/isochrone_engine.exe` 和 `Release/isochrone_engine.exe` 各通过 318 项相关回归，无跳过；路网前端测试 25 项通过，`npm run build` 通过。C++ 核心未修改，本轮未重新编译。两个第三方弃用警告不影响结果。

两项旧回归曾要求历史节点下限或路线必须经过 `j:` 推定连接，已改为生成图与引擎输入一致、所有路线段引用真实存在边的校验，避免要求恢复源拓扑后仍保留猜测补线。完整 UI 测试未作为本轮验收；历史 UI 测试中的未定义旧控制函数不在此次路网修改范围。

生成图结构错误和孤立节点均为零，源图可确定性重建；实际导出脚本重生成的引擎 JSON 与仓库文件 SHA-256 一致：`89faaf728a64e2f379eda929b34e10af6eb36fb96f57be6abfbe7243be556e55`。已有分析上下文保存旧请求图，前端需重新发起分析后才会采用新路网；本轮未清理用户旧报告。

生成顺序：在 `frontend` 下运行 `node scripts/build-demo-road-graph.mjs --write`，再从仓库根目录运行 `.venv/Scripts/python.exe backend/scripts/export_synthetic_preview.py`。不重新采集底图，不直接手改生成 JSON。对比 SVG、路口图册和 API 下载缓存仅保存在本地校对目录，不参与运行、不提交仓库。
